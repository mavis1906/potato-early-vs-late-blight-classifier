This project involved developing a CNN-based web application to classify potato leaf images into early blight and late blight.
The libraries used includes; datasets obtained from Kaggle, numpy, matplotlib, jupyter notebook, tensorflow and keras from tensorflow and finally vs code for its terminal and streamlit for deployment.
The sub-folders train, validation and test inside the dataset folders was used to house data gotten from kaggle.
These datas was used to train the AI model created using numpy,matplotlib and keras from tensorflow in the notebook.
After training, validation and testing was completed, the App.py folder was used to store the user interface of the app.
immediately after all the folders were created, we used git to commit and push it to our already created repository.
The final step came in form of deployment, where we created a streamlit account, connected it to our github and then deployed our code.

The huddles encountered were, setting up the jupyter notebook, the 100MB github protocol; which was resolved by using tflite version of tensorflow and finally the python vwesion blocking deployment.
this was overcame by reducing the python version in streamlit, creating a file and pushing it to github with a python version less than 3.12
